## 사용 규칙

1. **"프로젝트 기록을 읽어줘"** 라고 하면, 위에 등록한 페이지를 Notion MCP로 읽어서 보여준다.
2. **"오늘 작업을 기록해줘"** 라고 하면:
   - 먼저 그 페이지의 기존 내용을 읽는다.
   - 반영할 변경안을 사용자에게 보여준다.
   - 사용자가 확인하면 저장하고, 저장 후 다시 읽어 결과를 확인한다.
3. 읽기나 저장에 **실패하면 성공했다고 말하지 않는다.** 실패 사실을 그대로 알린다.
4. **다른 페이지로 바꾸거나 새 페이지를 만드는 것**은 먼저 사용자에게 확인한다.
5. 주소(URL)나 페이지 ID는 **추측하거나 만들어 쓰지 않는다.** 항상 위 등록 값을 사용하고, 불확실하면 Notion MCP로 다시 확인한다.
